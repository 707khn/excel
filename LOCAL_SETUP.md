# Установка Excel Manager в локальной сети (без интернета/облака)

Инструкция для отдела ИТ. Сервер работает **полностью внутри офисной сети**,
данные хранятся локально на серверном ПК (база SQLite + файлы на диске).

## Требования к серверному ПК
- Windows 7 Pro 64-bit (или новее)
- ~2 ГБ свободного места
- **Python 3.8.10 (Windows x86-64)** — последняя версия Python с поддержкой Win 7
  Скачать: https://www.python.org/downloads/release/python-3810/
  («Windows installer (64-bit)»). При установке отметить **Add Python to PATH**.

## Шаги установки

1. **Скопировать репозиторий** на серверный ПК, например в `C:\ExcelManager`.

2. **Запустить `setup.bat`** (двойной клик).
   Он создаст виртуальное окружение, установит зависимости и `.env`.

3. **Отредактировать `.env`** (открыть Блокнотом). Обязательно задать:
   - `ADMIN_EMAIL` — почта первого администратора (это логин)
   - `ADMIN_PASSWORD` — надёжный пароль администратора
   - `SECRET_KEY` — случайная строка ~64 символа (можно сгенерировать командой:
     `venv\Scripts\python -c "import secrets; print(secrets.token_hex(32))"`)

4. **Узнать IP-адрес сервера**: открыть `cmd`, ввести `ipconfig`,
   взять строку **IPv4-адрес**, например `192.168.1.50`.

5. **Открыть порт 8000 в брандмауэре Windows**:
   Панель управления → Брандмауэр Windows → Дополнительные параметры →
   Правила для входящих подключений → Создать правило → Для порта →
   TCP, порт `8000` → Разрешить подключение → Применить.

6. **Проверить запуск вручную**: запустить `run.bat`. В браузере на другом ПК
   открыть `http://192.168.1.50:8000` — должна появиться страница входа.
   Войти под учёткой администратора из `.env`. Остановить: Ctrl+C.

7. **Включить автозапуск при загрузке ПК** (рекомендуется):
   - Скачать **NSSM**: https://nssm.cc/download (взять `win64\nssm.exe`),
     положить `nssm.exe` рядом со скриптами (в `C:\ExcelManager`).
   - Запустить **`install_service.bat` от имени администратора**
     (правый клик → «Запуск от имени администратора»).
   - Теперь сервер стартует сам при включении ПК, без входа в систему.
   - Убрать автозапуск можно через `uninstall_service.bat` (от администратора).

## Использование
- Сотрудники заходят в браузере: `http://<IP-сервера>:8000`
- Администратор в веб-интерфейсе:
  - создаёт пользователей (вкладка «Пользователи»),
  - загружает Excel-файлы (вкладка «Файлы»),
  - выдаёт права на чтение/редактирование конкретным сотрудникам,
  - смотрит журнал действий (вкладка «Логи»).
- Несколько сотрудников могут редактировать один файл одновременно
  (изменения ячеек синхронизируются в реальном времени).

## Резервное копирование
Периодически (например, ежедневно по расписанию) копировать в безопасное место:
- файл базы данных `excel.db`
- папку `data\` (загруженные файлы)

## Если автозапуск без NSSM
Упрощённый вариант (требует автоматического входа в Windows):
создать ярлык для `run.bat` и положить его в папку автозагрузки
(`Win+R` → `shell:startup` → вставить ярлык). Минус: сервер запустится
только после входа пользователя в систему.

## Решение проблем
- **`setup.bat` не находит Python** — переустановить Python 3.8.10 с галочкой
  «Add Python to PATH», перезапустить `setup.bat`.
- **Не устанавливается какой-то пакет** — возможно, для него нет готовой сборки
  под Python 3.8. Зафиксировать более старую версию в `requirements.txt`
  (например, понизить `cryptography`) и повторить установку.
- **С других ПК не открывается** — проверить правило брандмауэра (порт 8000)
  и что оба ПК в одной локальной сети; проверить IP через `ipconfig`.

> Безопасность: Windows 7 не получает обновлений с 2020 г. Держите серверный ПК
> только внутри офисной сети, без прямого доступа из интернета.
